SnowSMP Core — Privacy Policy

Last updated: February 2026

1. Information Collected

The Bot may process the following data:

  • Discord User IDs
  • Discord Server IDs
  • Message metadata (for logging purposes)
  • Command usage

2. Purpose of Data Collection

This data is used only for:

  • Bot functionality
  • Logging and moderation
  • System automation
  • Server management

3. Data Storage

Data is stored securely and is not sold, shared, or distributed to third parties.

4. Data Removal

Server administrators may request removal of stored data.

5. Security

Reasonable measures are taken to protect stored information.

6. Changes

This policy may be updated at any time.

7. Contact

Contact SnowSMP staff for privacy concerns.
