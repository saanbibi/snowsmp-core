# SnowSMP Core

SnowSMP Core is the central system bot powering the SnowSMP Discord and Minecraft server infrastructure.

## Features

- Core automation and system coordination
- Integration with SnowSMP service bots
- Logging coordination and server event handling
- Command management and system control
- Infrastructure support for VC, Logs, Timeline, and Music bots

## SnowSMP Bot Ecosystem

- SnowSMP Core — Central system controller
- SnowSMP VC — Voice chat integration
- SnowSMP Server Logs — Server event logging
- SnowSMP Chat Logs — Chat message logging
- SnowSMP Command Logs — Command tracking
- SnowSMP Timeline — Event timeline tracking
- SnowSMP Music — Music playback system
